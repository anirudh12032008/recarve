# maths-2026-09-11 — Mathematics 1

## Summary

Integration by substitution, start to finish. The rule was motivated as the
chain rule run backwards: if differentiating $F(g(x))$ produces
$F'(g(x))g'(x)$, then an integrand of that shape must have come from
$F(g(x))$. Three worked examples followed, each chosen to make a different
point — spotting $g'(x)$ already present, adjusting by a constant when it is
almost present, and changing the limits on a definite integral rather than
substituting back. The class was warned twice that forgetting to change the
limits is the single most common way to lose marks on this topic.

## Key Points

- **The rule**
  - $$\int f(g(x))\,g'(x)\,dx = \int f(u)\,du \quad \text{where } u = g(x)$$
  - It is the chain rule read right to left

- **Step one is always the same**
  - Pick $u = g(x)$, the inside function
  - Compute $du = g'(x)\,dx$
  - Replace until nothing in $x$ is left; if something remains, the choice of
    $u$ was wrong

- **Example 1 — $g'(x)$ already there**
  - $\int 2x\cos(x^2)\,dx$, take $u = x^2$, $du = 2x\,dx$
  - Becomes $\int \cos u\,du = \sin u + C = \sin(x^2) + C$

- **Example 2 — adjust by a constant**
  - $\int x e^{x^2}\,dx$, take $u = x^2$, $du = 2x\,dx$, so $x\,dx = \frac{1}{2}du$
  - Becomes $\frac{1}{2}\int e^u\,du = \frac{1}{2}e^{x^2} + C$

- **Example 3 — definite, change the limits**
  - $\int_0^2 x(x^2+1)^3\,dx$, take $u = x^2+1$
  - When $x=0$, $u=1$; when $x=2$, $u=5$
  - $\frac{1}{2}\int_1^5 u^3\,du = \frac{1}{8}\left[u^4\right]_1^5 = \frac{625-1}{8} = 78$
  - No substituting back, because the limits moved with the variable

## Questions

**1. Why does substitution work? State it in one sentence.**

<details><summary>Answer</summary>

Because it is the chain rule reversed: differentiating $F(g(x))$ gives
$F'(g(x))g'(x)$, so an integrand of that form integrates back to $F(g(x))$.

</details>

**2. Evaluate $\int 2x\cos(x^2)\,dx$.**

<details><summary>Answer</summary>

Let $u = x^2$, so $du = 2x\,dx$. The integral becomes:
$$\int \cos u\,du = \sin u + C = \sin(x^2) + C$$

</details>

**3. Evaluate $\int_0^2 x(x^2+1)^3\,dx$, changing the limits.**

<details><summary>Answer</summary>

Let $u = x^2 + 1$, so $du = 2x\,dx$ and $x\,dx = \frac{1}{2}du$.

Limits: $x = 0 \Rightarrow u = 1$, and $x = 2 \Rightarrow u = 5$.

$$\frac{1}{2}\int_1^5 u^3\,du = \frac{1}{2}\left[\frac{u^4}{4}\right]_1^5
= \frac{1}{8}(625 - 1) = 78$$

</details>

**4. A student substitutes $u = x^2+1$ in a definite integral but leaves the limits as 0 and 2. What goes wrong?**

<details><summary>Answer</summary>

The limits 0 and 2 are values of $x$, not of $u$. Evaluating the $u$-integral
between them computes the area over the wrong interval. Either change the
limits to $u = 1$ and $u = 5$, or substitute back to $x$ before evaluating.

</details>
